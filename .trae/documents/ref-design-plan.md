# 修改 AI 应用广场首页为参考图设计风格

## 参考图分析

通过像素级分析用户上传的参考图 (1075x713px)，识别出以下关键设计特征：

| 特征 | 参考图 | 当前状态 |
|------|--------|----------|
| 整体背景 | **白色** (RGB 255,255,255) | 白色 |
| 侧边栏 | **无深色侧边栏**，左侧区域为白色 | 已改为暗色 (#16161a) ← 需要恢复 |
| 卡片布局 | **彩色卡片网格**，每张卡片有独特颜色 | 小图标+文字的紧凑卡片 |
| 卡片颜色 | 紫(93,92,222)、粉(222,180,165)、蓝(171,159,230)、绿(67,171,141)、黄(224,149,50) | 统一白色底+emoji图标 |
| 卡片图标 | **大尺寸彩色渐变图标**（占卡片主体） | 小emoji图标(40-48px) |
| 水平布局 | **横向滚动卡片行**（约8列变化区域） | 横向滚动但卡片小 |
| 内容结构 | 顶部区域→多行卡片→底部输入区 | 品牌标题→输入框→3行模型列表 |

**核心差异：参考图是大彩色卡片为主的 App Store / Bot 市场风格，当前是小emoji图标+文字的紧凑列表风格**

---

## 修改方案

### 改动 1：恢复侧边栏为浅色

**文件：** `app/globals.css`

参考图无深色侧边栏。需要将之前改的暗色侧边栏恢复为浅色。

```css
/* 当前（之前改的） */
--sidebar: #16161a;
--sidebar-foreground: #e4e4e7;
--sidebar-accent: #27272a;
--sidebar-accent-foreground: #fafafa;
--sidebar-border: #2a2a30;

/* 恢复为 */
--sidebar: #F7F8FB;
--sidebar-foreground: #09090B;
--sidebar-accent: #F4F4F8;
--sidebar-accent-foreground: #09090B;
--sidebar-border: #E4E4E7;
```

---

### 改动 2：重新设计模型卡片为彩色大卡片

**文件：** `components/workspace/model-list-row.tsx`

当前模型卡片是小图标(40-48px emoji) + 文字名称的紧凑风格。需要改为参考图中的**大彩色渐变图标卡片**风格：

- 卡片尺寸：从 `w-[100px]` 增大到 `w-[160px]`
- 图标区域：从 `w-10 h-10` 增大到 `w-14 h-14`，并使用**渐变背景色**
- 卡片背景：保持白色，但增加 `shadow-sm` 阴影
- 圆角：`rounded-xl`（12px）
- 去掉 Badge 标签
- 添加模型名称下方的简短描述文字

具体修改：

1. **卡片尺寸**：compact 模式从 `w-[100px]` → `w-[160px]`
2. **图标容器**：从 `w-10 h-10 bg-secondary` → `w-14 h-14 bg-gradient-to-br` + 模型专属渐变色
3. **卡片样式**：添加 `shadow-sm hover:shadow-md`，圆角 `rounded-xl`
4. **模型名称**：字体从 `text-xs` → `text-sm`

---

### 改动 3：给每个模型定义专属渐变色

**文件：** `lib/mock-data.ts`

当前模型数据只有 `logo`（emoji）和 `color` 字段。需要添加 `gradient` 渐变色字段，参考图中检测到的颜色：

```typescript
// 参考图中的颜色
gradients: {
  purple: 'from-violet-500 to-indigo-600',  // RGB(93,92,222)
  pink:   'from-pink-400 to-rose-500',       // RGB(222,180,165)
  blue:   'from-blue-400 to-violet-500',     // RGB(171,159,230)
  green:  'from-emerald-400 to-teal-500',    // RGB(67,171,141)
  yellow: 'from-amber-400 to-orange-500',    // RGB(224,149,50)
  sky:    'from-sky-400 to-blue-500',        // RGB(2,143,224)
}
```

---

### 改动 4：首页布局调整

**文件：** `components/workspace/home-content.tsx`

参考图的结构是：顶部区域→多行彩色卡片→底部输入。需要：

1. **去掉顶部大标题**：删除 "AI 应用广场" 标题和图标
2. **输入框位置**：移到页面最底部（固定定位）
3. **模型卡片行**：增大行间距，给卡片更多空间
4. **整体背景**：保持白色

---

### 改动 5：nav-panel 细节恢复

**文件：** `components/workspace/nav-panel.tsx`

恢复之前为暗色侧边栏做的适配改动（搜索按钮、对话列表项图标背景等）。
