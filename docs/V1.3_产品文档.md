## 一、功能概览

### 1.1 产品定位

AI APP Market 是一个**集成化智能应用市场**，面向内容创作者，提供文案生成、图片处理、视频制作、音频处理四大类 AI 能力，通过统一的"智点"计费体系实现一站式AI内容生产。

### 1.2 核心能力

| 模块 | 能力说明 | 包含智能体数量 |
|------|---------|--------------|
| 文案模块 | AI视频脚本生成、文案转视频 | 2 个 |
| 图片模块 | 图片生成动态视频 | 1 个 |
| 音频模块 | 语音转文字、文字转语音、视频转文字 | 3 个 |
| 视频模块 | 视频翻译、配音、字幕生成、去水印 | 4 个 |

### 1.3 用户角色

| 角色 | 说明 |
|------|------|
| 游客 | 可浏览智能体广场、查看模型列表，无法使用任何功能 |
| 注册用户 | 可使用全部智能体、充值、查看用量/支付记录 |

### 1.4 计费体系

- **货币单位**：智点
- **兑换比例**：1元 = 1000智点
- **扣费方式**：按次扣费，每次调用智能体或模型时预先扣除对应智点
- **充值方式**：微信 / 支付宝
- **预设套餐**：¥10 / ¥50 / ¥100 / ¥500，也支持自定义金额（¥0.01 ~ ¥50,000）

## 三、页面功能说明

### 3.1 智能体详情页（AgentShell）
路由：`/agent/[id]`

页面布局：左右分栏（移动端上下堆叠）

**左侧信息面板**：
- 返回按钮（→ 智能体广场）
- 智能体图标（渐变色圆角方块 + Lucide图标）
- 名称 + 描述（最多2行截断）
- 分割线
- 双列信息网格：消耗智点 | 平均耗时

**右侧Tab区**（3个Tab）：
- **场景介绍Tab**：根据智能体ID渲染专属Intro组件（10个智能体各有独立Intro），无专属Intro的智能体使用通用场景卡片（AgentSceneCards）
- **体验应用Tab**：包含输入区 + 参数配置 + 生成按钮 + 进度条 + 结果展示。5个智能体有专属体验组件（text-to-speech, topic-to-copywriting, copywriting-to-video, image-to-video, video-translate），其余使用通用AgentInputArea
- **历史任务Tab**：任务列表，展示字段：任务名称、任务状态、创建时间、结果预览（缩略图/文本摘要）
  - **Hover操作按钮**（鼠标悬停时显示）：
    - 文本类结果任务：复制按钮、删除按钮
    - 媒体类结果任务（图片/音频/视频）：下载按钮、删除按钮

### 3.2 智能体广场（AgentHome）
视图模式：`agent-home`

- 顶部：分类Tab筛选（全部 / 文案 / 图片 / 音频 / 视频），根据 `agentCategories` 渲染
- 内容区：智能体卡片网格
- 卡片信息：封面图（支持hover视频）、名称、简介、消耗智点、平均耗时
- 点击卡片 → 切换到 `agent-detail` 视图

## 五、操作流程

### 5.1 智能体使用流程

```
1. 用户进入工作台 → 点击导航面板"智能体市场"入口
2. 浏览智能体广场 → 可按分类Tab筛选
3. 点击感兴趣的智能体卡片 → 进入智能体详情页

   - 文本型：在文本框中输入内容
```

## 六、校验规则

### 6.1 文件上传校验

| 校验项 | 规则 | 错误提示 |
|--------|------|---------|
| 文件格式 | 必须在智能体的 `acceptedFiles` 列表中 | "不支持的文件格式，请上传 {格式列表} 格式" |
| 文件大小 | 不能超过 `maxFileSize`（MB） | "文件大小不能超过 {N}MB" |
| 文件必传 | inputType为file或both时，提交前必须有文件 | "请先上传文件" |
| 文件数量 | 当前仅支持单文件上传 | — |

### 6.2 文本输入校验

| 校验项 | 规则 | 错误提示 |
|--------|------|---------|
| 非空 | inputType为text或both时，提交前文本不能为空 | "请输入内容" |
| 最大长度 | 文本内容不能超过5000字 | "内容不能超过5000字" |
| 对话输入非空 | 发送消息时输入框不能为空 | 不发送（按钮disabled） |
| 必选模型 | 发送消息前至少选择一个模型 | "请先选择一个模型" |

### 6.3 参数配置校验

| 参数类型 | 校验规则 | 说明 |
|---------|---------|------|
| Select | 有默认值，无需额外校验 | 用户必选一项（radio行为） |
| Switch | 布尔值，无校验 | 开/关 |
| Slider | 不超出min/max范围 | 控件本身限制，无需额外校验 |
| Text | 无强制校验 | 自由输入，可为空 |

### 6.4 智点余额校验

| 校验项 | 规则 | 处理方式 |
|--------|------|---------|
| 余额充足 | 用户余额 >= 本次调用消耗智点 | 正常扣费执行 |
| 余额不足 | 用户余额 < 本次调用消耗智点 | 弹出充值弹窗（RechargeModal） |
| 未登录 | 用户未登录状态 | 弹出登录弹窗（LoginModal） |

### 6.5 登录表单校验

| 校验项 | 规则 | 错误提示 |
|--------|------|---------|
| 手机号格式 | 必须为11位数字 | "请输入有效的11位手机号" |
