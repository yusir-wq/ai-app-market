## 一、AI 语音转文字（agent-speech-to-text-experience.tsx）

### 1.1 移除生成设置选项
- **移除项**：区分说话人、自动添加标点、输出时间戳
- **保留项**：识别语言下拉框、生成内容摘要 Switch
- 同步清理对应的状态变量（`distinguishSpeaker`、`punctuation`、`timestamps`）

### 1.2 费用动态化
- 关闭"生成内容摘要"时：**20 智点/次**（约 0.02 元）
- 开启"生成内容摘要"时：**30 智点/次**（约 0.03 元）
- 使用指南卡片、生成按钮下方提示、生成结果标题栏、历史详情弹窗中的费用显示全部同步更新

### 1.3 智能总结显示逻辑
- **开启摘要时**：生成完成后自动显示总结文本（`summaryStarted` 设为 `true`），无需点击"开始总结"
- **关闭摘要时**：显示智能总结初始页（机器人图标 + "开始总结"按钮）
- 切换摘要开关时自动重置 `summaryStarted` 状态

### 1.4 移除操作按钮和输入框
- 移除智能总结区域的"重新生成"按钮
- 移除智能总结区域的"输入指令"对话输入框
- 仅保留"复制"按钮
- 同步清理未使用的导入（`ArrowsClockwise`、`PaperPlaneTilt`）和函数

### 1.5 未开启摘要时隐藏智能总结面板
- 当 `summarize` 为 `false` 时，生成结果区域仅显示转写内容，不渲染右侧"智能总结"面板
- 布局从 `md:grid-cols-[3fr_2fr]` 自适应为单列全宽

### 9.2 统一后的规范样式

```tsx
<AlertDialogContent className="rounded-[12px] max-w-[420px]">
  <AlertDialogHeader>
    <AlertDialogTitle className="text-[18px] font-medium text-[#111827]">
      确认删除
    </AlertDialogTitle>
    <AlertDialogDescription className="text-[14px] text-[#6B7280]">
      删除后，这个文件将被彻底清除且无法找回，确认要删除吗？
    </AlertDialogDescription>
  </AlertDialogHeader>
  <AlertDialogFooter>
    <AlertDialogCancel className="h-10 rounded-[8px] text-sm border-[#E5E7EB] text-[#374151] bg-white">
      取消
    </AlertDialogCancel>
    <AlertDialogAction className="h-10 rounded-[8px] text-sm bg-[#4F46E5] hover:bg-[#4F46E5]/80 text-white">
      确认删除
    </AlertDialogAction>
  </AlertDialogFooter>

```

### 9.3 关键变更点
| 项目 | 修改前 | 修改后 |
|---|---|---|
| 标题字重 | `font-semibold` (600) | `font-medium` (500) |
| 标题字号 | `text-base` / `text-[16px]` | `text-[18px]` |
| 描述文案 | "删除后无法恢复。确认要删除这条记录吗？" | "删除后，这个文件将被彻底清除且无法找回，确认要删除吗？" |
| 描述颜色 | `text-muted-foreground` | `text-[#6B7280]` |
| 按钮高度 | `h-9` (36px) | `h-10` (40px) |
| 取消按钮 | 无边框 | `border-[#E5E7EB] bg-white text-[#374151]` |
| 确认按钮 | `bg-destructive`（红色） | `bg-[#4F46E5]`（品牌蓝） |
| 确认文案 | "删除" | "确认删除" |
