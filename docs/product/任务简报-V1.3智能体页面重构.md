## 一、设计规范摘要

### 1.1 产品定位
- **目标用户**：AI 小白用户
- **核心价值**：多模型、多工具、便宜好用
- **模板工具**：AI 换背景（`#/image-tools/ai-background`）
- **复用工具**：AI 扩图、AI 写真、AI 商品海报、AI 风格转换、AI 配色重绘

### 1.2 核心色彩

| 名称 | 色值 | 用途 |
|------|------|------|
| 主色 | `#575ce9` | 品牌主色、链接、图标、焦点 |
| 强调主色 | `#4f55ec` | 主按钮、按钮悬停 |
| 浅主色背景 | `#f0f3ff` | 选中背景、hover 浅背景 |
| 页面底色 | `#f8faff` | 页面画布背景 |
| 左侧导航底色 | `#f7f9ff` | Sidebar 背景 |
| 表面白色 | `#ffffff` | 卡片、浮层、弹窗 |
| 主标题 | `#202434` | 标题、重要文字 |
| 正文 | `#3f4558` | 段落、描述 |
| 辅助文字 | `#8a91a6` / `#9097aa` | 次要信息 |
| 弱提示 | `#b2b8c8` | 占位符、禁用 |
| 常规线 | `#e7ebf5` | 边框、分割线 |
| 危险色 | `#d92d20` | 删除、错误 |

### 1.3 字体规范
- **字体族**：Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif
- **左侧菜单**：`14px/400`
- **左侧返回入口**：`12px/400`
- **Section 标题**：`18px`
- **H2 标题**：`26px/560`
- **正文**：`16px/400`
- **标签/小字**：`11px/500`
- 不要随意加粗，只有标题、关键数字、选中态才提高字重

### 1.4 尺寸与间距

| 项目 | 数值 |
|------|------|
| Sidebar 展开宽度 | `252px` |
| Sidebar 折叠宽度 | `76px` |
| 内容最大宽度 | `1440px` |
| 内容最小宽度 | `1080px` |
| 页面最小验收宽度 | `1400px` |
| 内容安全间距 | `34px` |
| 主内容区内边距 | `18px 12px 0 0` |
| 菜单项间距 | `4px` |
| 基础间距档位 | `8px` |

### 1.5 圆角规范

| 组件 | 圆角 |
|------|------|
| 标签/小徽章 | `4px` |
| 输入框/下拉框 | `6px` |
| 普通按钮 | `6px` |
| 主按钮 | `10px` |
| 卡片/弹窗 | `12px` |
| 头像/徽标 | 圆形 |

### 1.6 阴影规范

| 用途 | 阴影值 |
|------|--------|
| 基础卡片 | `0 2px 12px rgba(0,0,0,0.08)` |
| 悬浮状态 | `0 4px 20px rgba(0,0,0,0.12)` |
| 弹窗/浮层 | `0 8px 30px rgba(0,0,0,0.16)` |
| 主面板 | `0 8px 22px rgba(38,44,72,0.026-0.028)` |

### 1.7 图标规范
- UI 图标统一使用 **Phosphor Icons**（regular + duotone）
- 品牌/厂商/模型图标必须使用**真实品牌资源**
- 工具功能图标 → Phosphor；模型/厂商识别图标 → 真实品牌资源

### 1.8 关键交互原则
- 所有可点击区域 hover 必须是鼠标手
- hover 不改变文字色和图标色，只改变轻背景、透明度、辅助动作显隐
- 左侧菜单：hover 淡白，active 纯白
- 生成后自动滚动到结果区域
- 下载前必须弹确认窗口
- 错误提示必须可见，不藏在按钮下面

## 三、关键约束

### 3.1 技术约束
- **框架**：Next.js 16 + React 19 + Tailwind CSS v4
- **路由**：保持单路由 `/`，通过 `viewMode` 状态切换视图（本次不改路由）
- **UI 库**：shadcn/ui new-york 风格
- **样式**：Tailwind v4 CSS-first，无 `tailwind.config`
- **图标**：当前项目使用 `lucide-react`，规范要求使用 `Phosphor Icons`
- **字体**：Inter（已配置），中文回退已设置

### 3.2 框架约束
- 左侧框架不能改（品牌区、折叠按钮、底部账号区）
- Sidebar 展开 `252px`，折叠 `76px`
- 内容最大宽度 `1440px`，最小宽度 `1080px`
- 页面最小验收宽度 `1400px`
- 不要把工具内页做成独立 landing page

### 3.3 视觉约束
- 不要改左侧框架
- 不要把普通 hover 做成文字变蓝、图标变蓝
- 不要滥用加粗
- 不要用大阴影和大渐变制造"高级感"
- 不要让上传图、结果图变形
- 不要把合规提示藏起来
- 不要删除已确认的下载确认

### 3.4 代码现状约束
- 智能体广场和详情页都是 `Workspace` 内部的 `viewMode` 状态
- `components/workspace/workspace.tsx` 承载全局状态，较为庞大
- 10 个智能体的 Experience 组件命名不统一（部分带 `agent-` 前缀，部分不带）
- 历史任务数据硬编码在 `agent-detail-view.tsx`
- Mock 数据集中在 `lib/mock-data.ts`
- 当前使用 `lucide-react`，需要评估是否迁移到 `Phosphor Icons` 或兼容使用
