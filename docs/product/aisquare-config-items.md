# AI应用广场 - 前端写死内容配置项清单

> 目标：提取前端硬编码内容，评估后台可配置化范围，为后续版本迭代做准备。
> 后台已有模块：AI用户管理、AI交易管理、接入服务管理、服务日志管理、AI工具管理（图像/音视频/SEO配置）、任务奖励管理。

---

## 一、范围边界说明

### 建议后台化（运营会改、定价会调、内容会迭代）
- 首页Banner运营位
- 推荐模型 / 推荐工具
- 模型厂商分类标签
- 工具使用指南文案
- 工具定价（智点/次）
- 工具模板/场景/风格配置
- 音色列表
- 聊天页推荐模型分类
- SEO信息（页面标题、描述）
- 客服在线时间

### 建议写死（变更频率极低、法务/合规文本、技术说明）
- 导航菜单结构（一级/二级菜单项名称）
- 移动端底部导航标签
- ICP备案号、公网安备号
- 版权声明 "© 2026 站长之家 AI应用广场"
- 版权声明 / 合规声明文本（各工具页）
- 输入框操作提示（"Enter发送，Shift+Enter换行"等）
- 上传格式说明（"支持PNG、JPG、JPEG、WebP"）
- 输出格式选项（mp3等，技术约束）
- 在线客服 / 意见反馈按钮入口

### 需要进一步确认
- 平台Slogan（"多模型 · 多工具 · 便宜好用"、"AI万象 · 一呼即应"）：变更频率低，但属品牌文案，是否需要后台化？
- 工具分类Tab（图像工具/音视频工具）：仅2项，是否值得后台化？
- 声音分类Tab（全部/女声/男声）：是否跟随音色列表一起后台化？

## 三、PC/移动端差异配置汇总

以下配置项在PC端和移动端需要差异化展示：

| 配置项 | PC端 | 移动端 | 配置方式建议 |
|--------|------|--------|-------------|
| 推荐模型卡片数量 | 展示3个 | 横滑展示，数量可不同 | 后台配置PC数量和移动端数量 |
| 推荐工具卡片数量 | 展示3个 | 展示数量可不同 | 同上 |
| 首页Banner | 完整文案 | 文案可能截断或不同 | 后台可配置移动端简短文案 |
| 导航方式 | 左侧侧边栏 | 底部Tab栏 | 写死，结构差异在前端处理 |
| 工具页面布局 | 左侧子菜单+右侧操作区 | 上下堆叠 | 写死，前端布局差异 |
| 聊天页面布局 | 左侧历史列表+右侧聊天区 | 单列切换 | 写死，前端布局差异 |

> 说明：布局差异属于前端实现层面，不需要后台配置。需要后台配置的是内容数量和文案的差异化。

## 四、优先级建议

| 优先级 | 配置项 | 理由 |
|--------|--------|------|
| P0 | 工具定价（3.2、4.2） | 直接影响收入，定价会频繁调整 |
| P0 | 音色列表（4.7） | 音色会上下架，影响核心功能 |
| P1 | 工具模板/场景/风格（3.6-3.13） | 工具核心配置，后台已有菜单承接 |
| P1 | 推荐模型/推荐工具（1.8、1.12、2.5） | 运营需要灵活调整推荐内容 |
| P1 | 模型厂商标签（1.10） | 新增模型厂商时需同步 |
| P2 | 首页Banner运营位（1.1-1.4） | 运营推广内容，但变更频率可控 |
| P2 | 工具使用指南文案（3.1、4.1） | 文案优化，不紧急 |
| P2 | SEO信息（1.5、1.6、2.2） | 后台已有SEO配置菜单 |
| P3 | 客服时间、邀请文案等（5.1-5.5） | 变更频率低 |
