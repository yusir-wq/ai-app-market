## 二、逐页详细梳理

### 页面1：AI用户列表

**菜单路径**：AI用户管理 > AI用户列表
**路由**：`/user/list`
**核心功能**：查看用户列表、查看用户详情、给用户赠送智点

**业务场景**：
- 用户反馈问题时，通过手机号或用户ID查用户信息
- 用户投诉智点异常时，查看用户智点明细
- 运营活动时，给特定用户补发智点

**页面布局**：
- 筛选区：用户ID（文本输入）、手机号（文本输入）
- KPI卡片区：无
- 表格列：用户ID、绑定手机号、剩余智点、已消耗智点、累计购买总额(元)、操作
- 操作按钮：用户详情（弹窗）、赠送智点（弹窗）

**用户详情弹窗**：
- 基本信息区：用户ID、绑定手机号、用户名、昵称、剩余智点、已消耗智点、累计购买智点、累计赠送智点、累计购买总额、累计智点总额、注册时间、最近登录时间
- Tab页：购买明细（订单编号、支付金额、支付时间、支付方式、购买智点）、智点变动明细

**赠送智点弹窗**：
- 用户ID（只读）、赠送额度（输入框，仅支持正整数）

**操作步骤**：
1. 在筛选区输入用户ID或手机号 → 点击搜索
2. 点击"用户详情" → 弹窗显示基本信息 + 购买/智点变动明细
3. 点击"赠送智点" → 输入额度 → 确认

**现存问题**：
- 无KPI卡片（总用户数、总智点余额、总购买额等）
- 筛选条件太少（无注册时间、无智点余额范围）
- 无导出功能
- 用户状态不明确（无法区分活跃/封禁用户）
- 赠送智点无二次确认大额提示
- 用户详情中"累计购买智点"与"购买明细"数据存在不一致
- 智点变动明细为空时无引导说明

### 页面2：AI订单管理

**菜单路径**：AI交易管理 > AI订单管理
**路由**：`/order/list`
**核心功能**：查看订单列表（纯只读）

**业务场景**：
- 用户反馈支付问题时，查订单记录
- 核对收入数据

**页面布局**：
- 筛选区：订单编号（文本输入）、用户ID（文本输入）
- KPI卡片区：无
- 表格列：订单编号、用户ID、购买智点、支付金额、支付方式、支付时间
- 操作按钮：无（无任何行级操作）

**操作步骤**：
1. 输入订单编号或用户ID → 点击搜索
2. 查看列表（仅此而已）

**现存问题**：
- **无订单状态列**（无法区分已支付/待支付/已退款）
- **无行级操作**（不能查看订单详情、不能退款、不能标记处理）
- 支付方式显示不一致（`WECHAT_QR` vs `微信`，原始API值未本地化）
- 无KPI卡片（总订单数、总支付金额、今日收入等）
- 无日期范围筛选
- 无导出功能
- 本质上只是一个"只读列表"，不是真正的"订单管理"

### 页面3：AI模型管理

**菜单路径**：接入服务管理 > AI模型管理
**路由**：`/serve/aimodel`
**核心功能**：模型上下架、编辑模型描述/提示词/标签

**业务场景**：
- 新模型上线时，编辑模型描述和提示词后上架
- 模型有问题时，下架模型
- 调整模型前台展示内容（描述、短描述、预设提示词、标签）

**页面布局**：
- 筛选区：模型名称（文本输入）、状态（下拉）、计费方式（下拉）
- KPI卡片区：无
- 表格列：模型名称、前台分类、计费方式、状态（已上架/未上架）、最近修改时间、操作
- 操作按钮：编辑（弹窗抽屉）

**编辑抽屉**（三个区域）：
- **基础信息**：模型名称（只读）、前台分类（只读）、模型描述（文本域）、模型短描述（文本域）、上架状态（开关）
- **前台展示**：预设提示词（动态数组，最多4条）、前台标签（动态数组，最多4条）
- **计费方式**：是否开启计费（开关）、预扣智点数（数字输入）、计费方式（单选：灵活计费/固定计费）、固定售价(智点)（数字输入，仅选择固定计费时显示）

**操作步骤**：
1. 在列表中找到目标模型 → 点击"编辑"
2. 抽屉打开 → 修改模型描述/短描述
3. 在前台展示区域配置预设提示词和前台标签
4. 在计费方式区域配置计费开关、预扣智点数、计费方式和固定售价
5. 切换"上架状态"开关
6. 点击"保存"
7. 列表自动刷新

**现存问题**：
- **上架/下架需4步操作**（编辑→抽屉→切换开关→保存），是最高频操作却路径最长
- 无KPI卡片（模型总数、已上架数、未上架数）
- 无快捷上架/下架按钮（对比：图片工具管理有快捷启用/禁用）
- 无批量操作
- 无"新增模型"按钮（模型可能从上游自动同步，但运营不清楚来源）
- 无模型删除功能
- 模型名称和前台分类为只读，运营无法修改
- 编辑抽屉中"预设提示词""前台标签""预扣智点数""灵活计费/固定计费"等专业术语无解释
- 计费配置与模型成本管理（单价）割裂：模型编辑里配智点售价，成本管理里配上游单价，运营需要在两个页面之间切换才能理解"一个模型赚多少花多少"

### 页面4：模型成本管理

**菜单路径**：接入服务管理 > 模型成本管理
**路由**：`/serve/cost`
**核心功能**：查看模型单价配置、从上游渠道同步成本数据

**业务场景**：
- 定期同步上游模型成本，确保成本数据最新
- 查看某个模型的输入/补全/缓存价格
- 核对模型计费方式（按token/按次/按档位）

**页面布局**：
- 筛选区：模型名称（文本输入）、渠道（文本输入）、是否应用独属（下拉）、成本计算方式（下拉）
- KPI卡片区：无
- 表格列：模型名称、渠道、成本计算方式、是否应用独属、操作
- 操作按钮：详情（三栏布局弹窗）

**成本详情面板**（三栏布局）：
- 左栏：侧边导航（背景）
- 中栏：模型列表（可选择不同模型）
- 右栏：成本详情
  - 基础信息：模型名称（只读）、是否应用独属（只读）、渠道（只读）
  - 成本信息：成本计算方式（只读）、输入价格、补全价格、缓存价格 + "同步数据"按钮

**操作步骤**：
1. 在列表中找到目标模型 → 点击"详情"
2. 三栏布局打开 → 中栏选择模型 → 右栏显示成本
3. 点击"同步数据" → 从上游获取最新成本
4. 同步完成后查看更新后的价格

**现存问题**：
- **只有单价配置，无实际消耗汇总**（想知道某模型总共花了多少钱，要去任务日志查）
- **同步需逐个模型操作**，无批量同步
- 所有字段只读，无法手动覆盖成本
- 无"最后同步时间"显示
- 无KPI卡片（模型总数、各渠道模型数、总成本等）
- 无成本对比功能（无法对比多个模型的价格）
- 无导出功能
- "应用独属""渠道"等概念对运营不直观

### 页面5：模型任务日志

**菜单路径**：服务日志管理 > 模型任务日志
**路由**：`/logs/list`
**核心功能**：查看AI对话模型的任务调用日志和成本

**业务场景**：
- 查看模型调用的成功/失败情况
- 核对模型任务的成本消耗
- 排查用户反馈的模型调用问题

**页面布局**：
- 筛选区：任务ID、对话名称、模型、用户、模型类型（下拉）、扣费状态（下拉）
- KPI卡片区：任务总数、成功数、进行中数、失败后退款数、消耗智点、成本总计(元)
- 表格列：任务ID、对话名称、使用模型、模型类型、消耗智点、成本费用(元)、关联状态、执行时间

**操作步骤**：
1. 输入筛选条件 → 点击搜索
2. 查看KPI卡片了解总体情况
3. 在表格中查看具体任务明细

**现存问题**：
- **无日期范围筛选**（无法查"今天的成本""本周的成本"）
- KPI成本只反映模型任务，不含图片/音视频工具
- 列头被截断（"模..."、"关..."）
- 无导出功能
- 无按模型分组的成本汇总
- 退款率（145/1133 = 12.8%）较高但无告警提示

### 页面8：图片工具管理

**菜单路径**：AI工具管理 > 图片工具管理
**路由**：`/tools/imagetoolslist`
**核心功能**：图片工具上下架、配置计费、编辑场景

**业务场景**：
- 新增图片工具并配置计费
- 上下架图片工具
- 编辑工具的场景配置

**页面布局**：
- 筛选区：工具名称（文本输入）、启用状态（下拉）
- KPI卡片区：无
- 表格列：工具名称、前端排序、启用状态、创建时间、操作
- 操作按钮：工具编辑（弹窗）、场景编辑（弹窗）、启用/禁用（快捷操作）
- 顶部有"+ 新增图片工具"按钮
- 分页：共7条记录

**工具编辑抽屉**：
- 工具信息：工具名称、前端排序、是否需要结果审核（开关）、是否要求用户上传主图（开关）、是否要求场景配置主提示词（开关）
- 计费配置：计费方式（下拉）、是否开启计费（开关）、固定计费智点、预扣智点数

**操作步骤**：
1. 点击"新增图片工具"或找到已有工具点击"工具编辑"
2. 填写工具名称、排序、配置开关
3. 配置计费方式、智点数
4. 保存
5. 如需配置场景，点击"场景编辑"

**现存问题**：
- 编辑抽屉中"是否要求场景配置主提示词"等专业术语运营不理解
- "工具编辑"和"场景编辑"分开，运营不清楚两者的关系和边界
- 无KPI卡片（工具总数、已启用数）
- "固定计费智点"和"预扣智点数"需要一样但无自动联动或说明
- 无拖拽排序（前端排序只能输入数字）

### 页面10：SEO配置

**菜单路径**：AI工具管理 > SEO配置
**路由**：`/tools/seo`
**核心功能**：配置各AI工具页面的SEO标题、关键词、描述

**业务场景**：
- 新工具上线后，配置其页面的SEO信息以利于搜索引擎收录
- 优化已有工具页面的SEO关键词以提升搜索排名

**页面布局**：
- 筛选区：工具名称（文本输入）、工具类型（下拉）
- KPI卡片区：无
- 表格列：工具名称、页面名称、页面访问路径、页面标题、操作
- 操作按钮：编辑（弹窗）

**编辑弹窗**：
- 页面名称（只读）：如"AI风格转换"
- 页面访问路径（只读）：如"/1"
- 页面标题（文本输入）：浏览器标签页标题、搜索结果标题
- 页面关键词（文本输入）：搜索关键词
- 页面描述（文本域）：搜索结果摘要描述

**操作步骤**：
1. 在列表中找到目标工具 → 点击"编辑"
2. 弹窗打开 → 修改页面标题、关键词、描述
3. 点击"确定"保存

**现存问题**：
- 10条记录中仅1条配置了页面标题，其余页面标题为空——大部分工具SEO未配置
- 无"已配置/未配置"状态标识，运营不知道哪些还差
- 无批量编辑功能
- 无字符长度提示（SEO标题建议50-60字符，描述建议150-160字符）
- 页面访问路径为简单的"/1""/2"等数字路径，对SEO不友好
- 无预览功能（无法预览搜索引擎收录效果）

### 页面11：奖励数据概览

**菜单路径**：任务奖励管理 > 奖励数据概览
**路由**：`/reward/summary`
**核心功能**：无（空白页）

**页面布局**：
- 仅显示"欢迎来到系统后台"

## 三、跨页面问题分析

### 3.1 命名不一致

| 问题 | 具体表现 | 影响 |
|------|---------|------|
| 一级菜单前缀冗余 | 所有菜单带"AI"前缀，但后台本身就叫"AI应用广场运营后台" | 视觉噪音，菜单名变长 |
| "管理"后缀冗余 | "AI用户管理""AI交易管理""AI工具管理""任务奖励管理" | "管理"是默认动作，不需要重复说 |
| KPI卡片命名不一致 | 音视频日志"失败数" vs 模型/图片日志"失败后退款数" | 运营不确定两者是否同一含义 |
| 工具启用字段不一致 | 图片工具"启用状态" vs 音视频工具"是否启用" | 同一概念两种叫法 |
| 支付方式显示不一致 | "WECHAT_QR" vs "微信" | 原始API值未本地化 |

### 3.2 交互模式不一致

| 问题 | 具体表现 | 影响 |
|------|---------|------|
| 上下架/启用方式不一致 | 图片工具有列表快捷启用/禁用 ✓；模型管理需进编辑抽屉 ✗ | 运营需要记住不同操作方式 |
| 编辑入口不一致 | 模型管理只有"编辑"；图片工具有"工具编辑"+"场景编辑" | 概念混淆 |
| 详情入口不一致 | 用户详情是弹窗；成本详情是三栏布局；订单无详情入口 | 交互模式不统一 |
| 筛选字段数量差异大 | 用户列表2个字段 vs 模型任务日志6个字段 | 无统一规范 |

### 3.3 数据分散无法汇总

| 数据维度 | 分散位置 | 影响 |
|---------|---------|------|
| 用户智点 | 用户列表(剩余/已消耗) + 用户详情(购买/赠送明细) + 任务日志(消耗智点) + 订单(购买智点) | 无法一眼看到用户完整智点生命周期 |
| 模型成本 | 模型成本管理(上游单价) + 模型编辑抽屉(智点售价) + 模型任务日志(消耗) | 一个模型的"进价""售价""实际消耗"分散在三个地方，运营无法算出利润 |
| 总成本 | 模型任务日志 + 图片工具任务日志 + 音视频工具任务日志 | 三处成本需手动加总 |
| 工具状态 | 工具管理(启用/禁用) + 任务日志(成功/失败) | 工具健康度无统一视图 |

### 3.4 缺失KPI/统计汇总

| 页面 | 是否有KPI | 缺失的关键统计 |
|------|----------|---------------|
| 用户列表 | 无 | 总用户数、今日新增、总智点余额、总购买额 |
| 订单管理 | 无 | 总订单数、总支付金额、今日收入 |
| 模型管理 | 无 | 模型总数、已上架数、未上架数 |
| 模型成本管理 | 无 | 模型总数、各渠道分布、总成本 |
| 工具管理 | 无 | 工具总数、已启用数 |
| SEO配置 | 无 | 总工具数、已配置数、未配置数 |
| 模型任务日志 | 有 ✓ | — |
| 图片工具任务日志 | 有 ✓ | — |
| 音视频工具任务日志 | 有 ✓ | — |
| 奖励概览 | 无（空白页） | 全部 |

### 3.5 空页面/死页面

| 页面 | 问题 |
|------|------|
| 奖励数据概览 | 完全空白，仅"欢迎来到系统后台" |
| 首页Tab | 不是真正的首页/仪表盘，只是面包屑导航 |

### 3.6 数据格式问题

| 问题 | 具体表现 |
|------|---------|
| 成本精度过高 | 1315.6746005936（13位小数），应保留2位 |
| 大数字无千分位 | 923241 应为 923,241 |
| 列头截断 | "模...""关..." |
| 空值显示不友好 | 用户详情中"-"不如"未绑定"直观 |

### 3.7 筛选能力缺失

| 页面 | 缺失的筛选 |
|------|-----------|
| 全部13个页面 | 无一页面有日期范围筛选 |
| 用户列表 | 无注册时间筛选、无智点余额范围 |
| 订单管理 | 无订单状态筛选、无支付时间筛选 |
| 任务日志（3个） | 无日期范围（最关键的缺失） |
| 工具管理 | 无创建时间筛选 |

### 3.8 无帮助/提示系统

| 问题 | 具体表现 |
|------|---------|
| 专业术语无解释 | "应用独属""预扣智点""模型倍率配置""场景配置主提示词"等 |
| 表单字段无tooltip | 编辑抽屉中所有字段无hover提示 |
| 无操作引导 | 新运营不知道"场景编辑"和"工具编辑"的区别 |
| 无空状态引导 | 智点变动明细为空时无引导说明 |

### 3.9 无全局仪表盘

当前后台没有真正的"首页/仪表盘"，运营登录后看到的是空白的"欢迎来到系统后台"。没有一个页面能让运营快速了解：
- 今天有多少任务？总成本多少？
- 有多少模型上架？多少工具启用？
- 有多少新用户？多少新订单？
- 是否有异常（高失败率、高退款率）？
