## 2. 公共规则

- 本文档涉及的日期、当天和时间范围统一按中国标准时间(UTC+8)计算。"今日"为当日 00:00(含)至次日 00:00(不含);"本月"为当月首日 00:00(含)至次月首日 00:00(不含)。
- 所有列表和统计页面提供加载状态、空状态和失败提示;空状态支持重置筛选,失败支持重新加载。
- 金额展示:元,保留2位小数,千分位分隔。智点:整数。
- 转化率/成功率:分母为 0 时展示"—",保留1位小数。
- 菜单重组仅调整层级与显示名称,**原有路由 path 不变**;菜单级权限按原菜单项继续生效。
- 【待确认·开发】菜单权限绑定路由 path 还是显示名称?若绑定名称,本次重命名需同步权限配置。
- 全部KPI卡片与列表数据联动:筛选条件变化后,KPI数值按当前筛选结果重新计算。
