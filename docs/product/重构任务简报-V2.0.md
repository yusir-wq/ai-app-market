## 二、V2.0 设计规范（关键值）

### 2.1 框架

| 项 | 值 |
|--|------|
| 内容最大宽度 | `max-w-[1440px] mx-auto` |
| 安全间距 | `px-[34px]` |
| 页面底色 | `#FFFFFF` |
| 主色 | `#4f55ec` |
| 文字主色 | `#202434` |
| 文字次色 | `#3f4558` |
| 文字弱色 | `#8a91a6` |
| 卡片边框 | `#f0f2f8` |
| 内部分隔线 | `#e7ebf5` |
| 卡片背景（浅） | `#f8faff` |
| 卡片阴影 | `0 8px 22px rgba(38,44,72,0.028)` |
| 圆角（大卡片） | `18px` |
| 圆角（按钮） | `10px` / `6px` |

### 2.2 字体

| 层级 | 字号 | 字重 |
|------|------|------|
| 卡片标题 h3 | `18px` | `font-medium` |
| 正文 | `text-sm` | `font-normal` |
| 辅助提示 | `text-xs` / `text-[11px]` | `font-normal` |

**原则**：标题 `18px`，不随意加粗，不使用蓝色作为标题色。

### 2.3 按钮

- 主按钮：`bg-[#4f55ec] hover:bg-[#4f55ec]/80`，白色文字
- 描边按钮：`border-border`，hover 不改文字/图标/边框色
- 操作按钮：`variant="ghost"`，hover 只改背景色
- 生成按钮图标统一：`MagicWand`（`@phosphor-icons/react`，`weight="fill"`）
- **hover 状态只改变背景颜色，不改变文字、图标及边框的颜色**

### 2.4 Header

- 背景：`bg-white/96 backdrop-blur-[10px]`
- 全宽不受 `max-w-[1440px]` 约束
- 与内容区间距：`mb-9`

### 2.5 生成结果卡片标题

- 渐变背景只作用于标题行：`px-6 pt-6 pb-2`
- 内容区：`p-6 pt-4`（无渐变）
- 导出 TXT 按钮：`variant="ghost"`，与编辑/复制平级
- 标题右侧显示消耗智点数：`<span className="text-xs text-[#8a91a6]">消耗 {COST_POINTS} 智点</span>`

### 2.6 进度条组件规范（Slider）

**统一样式**：
```tsx
<div className="flex items-center gap-3">
  <input type="range" min={MIN} max={MAX} step={STEP} value={value} onChange={...}
    className="flex-1 h-2 rounded-full appearance-none cursor-pointer"
    style={{
      background: `linear-gradient(to right, #4f55ec ${((value - MIN) / (MAX - MIN)) * 100}%, #e7ebf5 ${((value - MIN) / (MAX - MIN)) * 100}%)`,
      WebkitAppearance: 'none'
    }}
  />
  <span className="inline-flex items-center justify-center min-w-[36px] h-5 px-1.5 text-[11px] font-medium text-muted-foreground bg-muted/60 rounded-md tabular-nums shrink-0">
    {value}秒
  </span>
</div>
```

**要点**：
- 移除进度条下方的 min/max 标签
- 数值显示移到进度条右侧，同一行显示
- 使用 `flex items-center gap-3` 布局

## 三、气泡卡片统一规范

> 所有 PopoverContent / SelectContent / 下拉面板必须遵循以下标准，**后续重构时直接复制**

| 属性 | 标准值 |
|------|--------|
| 圆角 | `rounded-[12px]` |
| 边框 | `border-[#E5E9F6]` |
| 阴影 | `style={{ boxShadow: 'rgba(43,49,78,0.11) 0px 18px 38px 0px' }}` |
| 头部分隔线 | `border-[#E5E9F6]` |
| 虚线上传行边框 | `border-dashed border-[#E5E9F6]` |

### 3.1 典型结构

```tsx
<PopoverContent
  side="bottom"
  align="start"
  className="w-[360px] p-0 overflow-hidden border-[#E5E9F6] rounded-[12px]"
  style={{ boxShadow: 'rgba(43,49,78,0.11) 0px 18px 38px 0px' }}
>
  <div className="px-4 py-3 border-b border-[#E5E9F6] bg-[#f8f9fc]">标题</div>
  <div className="p-4">内容</div>
</PopoverContent>
```

### 3.2 SelectContent 下拉选项

```tsx
<SelectContent className="rounded-[12px] border-[#E5E9F6]" style={{ boxShadow: 'rgba(43,49,78,0.11) 0px 18px 38px 0px' }}>
  <SelectItem value="xxx">选项</SelectItem>
</SelectContent>
```

### 3.3 声音选择卡片（如适用）

- 头像：`img` 标签，`w-9 h-9 rounded-full object-cover`
- 标签：数组渲染为多个独立 `span`，去掉逗号
- 名称：中文名，符合声音特性
- 头像图片路径：`/avatars/voice-{name}.jpg`（1024×1024）
- 设置按钮 hover：`text-[#3f4558]/60 → hover:text-[#4f55ec]`，`hover:bg-[#4f55ec]/[0.06]`

### 3.4 背景音乐气泡（SelectContent）

**关键交互规范（踩坑总结）：**

- **气泡宽度**：`w-[480px]`（两列网格，右侧内容需要足够空间）
- **选项不自动关闭**：`onValueChange` 只设值，不调 `setBgmSelectOpen(false)`
- **上传后保持开启**：`handleBgmUpload` 末尾显式 `setBgmSelectOpen(true)`
- **选中态**：`bg-[#F3F5FF] text-[#4F55EC]`

**选项卡片统一两行布局：**
```
第一行：[图标/上传按钮]  [名称]
第二行（未选中）：[时长]
第二行（选中）：[播放/暂停按钮] [进度条] [时间]
```

- 所有选项高度一致：`py-2`，无特征描述标签，仅保留时长
- "无背景音乐"时长行用透明占位保持高度：`text-transparent`
- 上传卡片未选中时显示时长，选中时显示播放控件 + 移除按钮
- 上传卡片最左侧为替换按钮（UploadSimple 图标 + 隐藏 file input）

## 五、输入框组件规范

### 5.1 文本输入框（Textarea）

**统一使用 `<Textarea>` 组件**，而非原生 `<textarea>`：

```tsx
<div className="flex-1 relative">
  <Textarea
    value={text}
    onChange={e => setText(e.target.value)}
    placeholder="输入内容…"
    className="min-h-[280px] h-full resize-none rounded-[12px] border border-[#e7ebf5] shadow-none bg-[#F8FAFF] focus-visible:ring-0 text-[13px] leading-7 placeholder:text-[#3f4558]/35"
  />
  <span className="absolute bottom-3 right-3 text-[11px] font-medium tabular-nums tracking-tight text-[#3f4558]/40">
    {text.length}/5000
  </span>
</div>
```

**要点**：
- 使用 `<Textarea>` 组件（来自 `@/components/ui/textarea`）
- 字数统计使用 `<span>` 而非 `<div>`，避免溢出
- 字数统计定位：`absolute bottom-3 right-3`
- 背景色：`bg-[#F8FAFF]`

### 5.2 防止重复提交

```tsx
function handleGenerate() {
  if (!text.trim()) { toast.error('请先输入内容'); return }
  if (isProcessing) { return }  // 防止重复提交
  setIsProcessing(true)
  // ...
}
```

## 六、生成历史弹窗规范

### 6.1 统一结构

所有应用的生成历史弹窗必须遵循以下结构：

```tsx
<div className="fixed inset-0 z-50 flex items-center justify-center bg-black/50" onClick={() => setSelectedHistoryItem(null)}>
  <div className="bg-white rounded-[16px] shadow-2xl max-w-[900px] w-full mx-4 max-h-[85vh] overflow-hidden" onClick={(e) => e.stopPropagation()}>
    {/* 标题区域 - 带渐变背景 */}
    <div className="px-6 py-4 flex items-center justify-between" style={{ background: 'linear-gradient(180deg, #f0f4ff 0%, #ffffff 100%)' }}>
      <div className="flex items-center gap-3">
        <h3 className="text-[18px] font-medium text-[#3f4558]">生成结果</h3>
        <span className="text-xs text-[#8a91a6]">消耗 {COST_POINTS} 智点</span>
      </div>
      <button onClick={() => setSelectedHistoryItem(null)} className="text-[#8a91a6] hover:text-[#3f4558] transition-colors"><X className="h-5 w-5" /></button>
    </div>
    {/* 内容区域 */}
    <div className="p-6 overflow-y-auto max-h-[65vh]">
      {/* 各应用特定内容 */}
      {/* 文件信息 - 靠在一起 */}
      <div className="mt-4 flex items-center gap-4 text-xs text-[#8a91a6]">
        <span>文件：{selectedHistoryItem.title}</span>
        <span>创建时间：{formatTime(selectedHistoryItem.time)}</span>
      </div>
      {/* 提示信息 */}
      <p className="text-xs text-muted-foreground/80 mt-3 flex items-center gap-1"><WarningCircle className="h-3 w-3" />AI生成内容，仅供参考，请勿用于违法违规用途。</p>
    </div>
  </div>
</div>
```

### 6.2 各应用弹窗内容

| 应用 | 布局 | 内容 |
|------|------|------|
| **STT** | 3:2 分栏 | 左侧：转写内容 + 操作按钮 + 音频播放器；右侧：智能总结 + 操作按钮 + 对话输入框 |
| **TTS** | 通栏 | 输入内容 + 操作按钮 + 音频播放器（含设置信息条） |
| **VideoToText** | 3:2 分栏 | 左侧：转写内容 + 操作按钮 + 音频播放器；右侧：智能总结 + 操作按钮 + 对话输入框 |
| **Copywriting** | 通栏 | 生成文案 + 操作按钮 |
| **CopywritingToVideo** | 3:2 分栏 | 左侧：视频预览 + 操作按钮；右侧：分镜脚本 + 操作按钮 |

### 6.3 操作按钮规范

- **转写内容/文案**：编辑、复制、导出 TXT、下载音频/视频
- **智能总结**：重新生成、复制
- **视频预览**：下载视频
- **分镜脚本**：编辑、复制、导出 TXT

### 6.4 要点

- ✅ 标题区域带渐变背景（`#f0f4ff → #ffffff`）
- ✅ 无分割线
- ✅ 显示历史记录内容（`selectedHistoryItem.result`）
- ✅ 每个内容区域下方有对应的操作按钮
- ✅ 下载按钮具体化（下载音频/下载视频/下载MP3）
- ✅ 只保留右上角 X 关闭按钮
- ✅ 添加"AI生成内容，仅供参考，请勿用于违法违规用途。"提示
- ✅ 文件信息靠在一起显示

## 七、组件化规范（避免重复问题）

### 7.1 体验页导出

```tsx
interface XxxExperienceProps {
  agent: Agent
  onBack: () => void
  onViewResult?: (resultId: string, fileName?: string) => void
}

export function XxxExperience({ agent, onBack, onViewResult }: XxxExperienceProps) {
  // 所有状态自包含，不从父组件接收 text/paramValues/isProcessing 等
}
```

### 7.2 agent-detail-view.tsx 路由

走全页面渲染（与 STT/TTS/VideoToText 相同）：

```tsx
{agent.id === 'xxx' ? (
  <XxxExperience agent={agent} onBack={onBack} onViewResult={onViewResult} />
) : (
```

### 7.3 图标库

统一使用 `@phosphor-icons/react`，**禁止**使用 `lucide-react`（已有文件逐步替换）。
已替换的文件：copywriting、subtitle、dubbing、translate、watermark-removal。

### 7.4 未使用导入必须清理

每次重构后运行 `npx next build`，出现 `... is declared but never read` 立即清理。

### 7.5 历史记录 resultId 必须匹配

历史记录的 `resultId` 必须与 `mockResultDetails` 中的 key 一致，否则点击"下载"会显示空白页。
- STT: `result-speech-to-text`
- TTS: `result-text-to-speech`
- VideoToText: `result-video-to-text`
- Copywriting: `result-topic-to-copywriting`

### 7.6 跨应用跳转机制

使用 CustomEvent 实现跨应用跳转（如文案生成→文案生视频）：
```tsx
// 发送方
window.dispatchEvent(new CustomEvent('navigateToAgent', { detail: { agentId, params } }))

// 接收方（workspace.tsx）
useEffect(() => {
  const handler = (e: Event) => {
    const { agentId, params } = (e as CustomEvent).detail
    // 设置预填文本、切换应用、显示 toast
  }
  window.addEventListener('navigateToAgent', handler)
  return () => window.removeEventListener('navigateToAgent', handler)
}, [])
```

## 十、开发流程规范（踩坑总结，后续必须遵守）

### 10.1 先理解需求再动手

> **核心原则**：除非需求非常明确（如"改为 18px"、"颜色换成 #4f55ec"），否则必须先确认理解再动手写代码。

| 用户表述 | 正确做法 | 错误做法 |
|----------|----------|----------|
| "太高了，缩小" | 问用户"需要缩小到什么程度？有参考目标吗？" | 直接猜一个值改上去 |
| "要对齐" | 自己打开浏览器核对视觉效果，按目标改好 | 凭代码推理猜一个固定值 |
| "参考 XX 区域" | 先读取参照物代码，理解其布局机制，再决定方案 | 不看参照物直接写 |
| "合并到文本中" | 确认数据模型，理解"合并"的具体含义 | 按字面意思拼接 |

### 10.2 视觉类需求必须浏览器验证

> **规则**：涉及"对齐""等高""同一水平线""视觉一致"等描述时，**第一步必须是打开浏览器截图/测量**，而不是直接改代码。

**执行流程**：
1. 改之前：打开浏览器截图，用 JS 测量当前实际像素值
2. 改完后：立即刷新截图对比，用 JS 测量确认数值一致
3. 不要依赖代码推理——CSS 的实际渲染结果可能和预期不同

### 10.3 响应式布局禁止混用固定值和自适应值

> **规则**：在同一 grid/flex 容器中，如果一侧使用了响应式布局（如 `aspect-video`、`flex-1`），另一侧**禁止使用固定像素高度**。

**正确做法**：
```tsx
{/* ✅ 正确：两侧都用 flex-1 自适应 */}
<div className="grid grid-cols-[3fr_2fr] gap-6 items-stretch">
  <div className="flex flex-col">
    <div className="flex-1">左侧内容</div>
    <div>底部按钮</div>
  </div>
  <div className="flex flex-col">
    <div className="flex-1">右侧内容</div>
    <div>底部按钮</div>
  </div>
</div>
```

**错误做法**：
```tsx
{/* ❌ 错误：左侧响应式，右侧固定值 */}
<div className="grid grid-cols-[3fr_2fr] gap-6">
  <div className="aspect-video">左侧（高度随宽度变化）</div>
  <div className="h-[320px]">右侧（固定值，永远对不齐）</div>
</div>
```

### 10.4 左右对称结构，子元素必须一一对应

> **规则**：当 grid 两列需要等高时，确保每列的子元素结构对称。如果左侧有 `标题 + 容器 + 按钮 + 提示文案`，右侧也必须有对应的占位元素。

**检查清单**：
- 两侧子元素数量是否相同？
- 每个对应子元素的高度是否一致？
- margin/padding 是否对称？
- 如果一侧有提示文案（如 `mt-[7px]` + 文字高度），另一侧必须有等高的占位 `<div>`

### 10.5 多轮修改时先确认方案再动手

> **规则**：当某个区域已经修改了 2 次以上，**停下来**，先向用户说明：
> 1. 当前的问题是什么（附截图/数据）
> 2. 我理解的期望效果是什么
> 3. 我打算怎么改
>
> 确认后再写代码，避免"改 → 不对 → 再改 → 还不对"的循环。
