# V1.6 盘点工作指南

> 目的:把剩余盘点工作流水线化,每页按固定流程走,产出直接进产品文档。
> 已验证:AI工具管理模块(画板)就是按这个方法做的——要素清点→命名改→字段定→结构化。

## 一、运营后台:剩余11页盘点

### 盘点范围与顺序(按运营使用频率)

| 顺序 | 页面 | 频率判断 |
|------|------|---------|
| 1 | 交易→订单列表 | 每天 |
| 2 | 用户→用户列表(+详情弹窗) | 每天 |
| 3 | 运营数据→三个调用日志 | 每周成本核对 |
| 4 | 交易→模型成本 | 同步操作高频 |
| 5 | 工具→音视频工具 | 上新/调价时 |
| 6 | 工具→SEO配置 | 低频 |
| 7 | 运营数据→奖励概览/奖励记录 | 低频 |
| 8 | 运营数据→数据总览 | 新页面无现状,跳过盘点直接按模板设计 |

### 每页五步盘点法

**第1步 要素清点(只记录,不判断)**
打开后台页面,抄下:全部表格列名、全部筛选项、全部按钮/操作项、弹窗内全部字段。
> 这步可以交给AI:你之前的做法"让AI访问后台"继续用,或截图给AI提取。

**第2步 过四问(逐项判断)**

| 问 | 判断标准(尺子) | 产出 |
|----|--------------|------|
| 命名:新运营不看解释能懂吗? | 技术词/英文缩写/内部黑话→改;能懂→不改 | 改名清单(旧→新+注释文案) |
| 信息:列表缺什么字段影响运营判断? | 说不出支撑的具体运营动作→不加 | 新增字段清单 |
| 查询:找一条记录点几步? | 该筛选条件一周用≥2次→加 | 筛选条件清单 |
| 操作:高频操作几步? | >2步的高频操作→加快捷入口 | 快捷操作清单 |

**第3步 定KPI(页面的"第一句话")**
问自己:运营每天打开这个页面,第一眼想看什么数字?看不看的数字不进卡片,每页≤4张。

**第4步 标改动**
按文档格式落表:优化项 | 🟡新增/🔵修改 | 说明。

**第5步 标数据依赖**
每个新增字段/KPI:现有接口有没有?
- 有→前端聚合,实现简单
- 没有→进开发问题清单(估工作量,可能被裁掉)

### KPI/字段定义模板(每个指标一行)

| 指标名 | 计算口径 | 格式 | 数据来源 | 更新时机 |
|--------|---------|------|---------|---------|
| 示例:今日收入 | 当日00:00至今、状态=已支付订单的实付金额合计,不含退款 | 元,保留2位 | 订单列表接口聚合/需新接口 | 进页面时 |

> 口径里最容易漏的是边界:退款算不算、未支付算不算、今日从几点算。开发问的永远是这些。

## 二、移动端交互:竞品调研→前端可开发清单

### 第1步 列页面清单(穷举)

L1(底部导航):广场、搜索、对话、图像、我的
L2(二级页):聊天页、图片工具页、音视频工具页、MCP市场、生成历史/结果、充值购买智点、购买记录、意见反馈

### 第2步 每页过统一检查表(8项,来自竞品共性)

| 检查项 | 标准 | 参照 |
|--------|------|------|
| 卡片布局 | 单列,信息完整 | Coze/GPT Store |
| 分类导航 | 一行横滑,不换行 | 即梦灵感页 |
| 输入区 | 高度≥44px,占位文案移动端化 | 通用 |
| 生成反馈 | 进度提示(进度条/骨架屏) | 即梦/可灵 |
| 结果展示 | 文字6-8行可滚动/图片4张候选 | ChatGPT/Poe/即梦 |
| 触控尺寸 | 可点元素≥44×44px | iOS/Android规范 |
| 字号 | 正文≥12px(推荐14-16px) | 通用 |
| 计费提示 | 发送前显示预扣智点(图标+数量) | Poe |

### 第3步 产出:页面×组件优化清单

每行 = 页面 | 组件 | 现状(截图) | 竞品参照 | 改法 | 优先级

优先级按流量路径排:广场(入口)>对话(转化)>图像/音视频(功能)>我的(低频)。

> 至此交给前端的 = 本清单 + 第三章12条修复,没有未定项。

### 竞品判断原则

- **两家以上竞品同做法→照抄**(如单列卡片、横滑标签),不用再纠结
- **只有一家做→存疑**,可能是该家特性,需结合自己用户场景判断
- **都不做→大概率不该做**(如移动端塞PC式参数面板)

## 三、分工原则

| AI做(机械盘点) | 你做(判断) |
|---------------|-----------|
| 打开页面提取字段/筛选/按钮清单 | 四问的"改不改、加不加"拍板 |
| 截图+跑8项检查表 | KPI选哪几个、口径边界定夺 |
| 对照竞品出"现状vs标准"差异 | 优先级排序 |
| 起草口径文案初稿 | 与琳娜/开发的沟通决策 |

## 四、执行节奏(估)

- 后台剩余11页:每页0.5-1小时(AI清点后人工判断为主),3-4个工作日
- 移动端13页:截图+检查表1天(AI可代劳大半),判断0.5-1天
- 全部完成后→评审(用《V1.6_评审决策清单.md》)
