# AI应用广场运营后台 — 布局与交互优化需求

## 一、背景

运营后台为新栏目，运营团队由其他同事兼任（1-2人，新人占比100%），培训方式为产品口头带教。当前后台菜单命名不直观、操作路径偏长、成本数据分散，导致上手门槛高、培训成本大。

本次优化目标：**在不新增功能模块、不改后端接口/数据结构、不动权限体系的前提下，通过菜单重组、布局调整、高频操作路径缩短、关键数据可视化呈现优化，让运营人员上手更快。**

## 二、现状分析

### 2.1 当前菜单结构（6个一级菜单，13个二级菜单）

| 一级菜单 | 二级菜单 | 路由 |
|---------|---------|------|
| AI用户管理 | AI用户列表 | `/user/list` |
| AI交易管理 | AI订单管理 | `/order/list` |
| 接入服务管理 | AI模型管理 | `/serve/aimodel` |
| | 模型成本管理 | `/serve/cost` |
| 服务日志管理 | 模型任务日志 | `/logs/list` |
| | 图片工具任务日志 | `/logs/imagetool/list` |
| | 音视频工具任务日志 | `/logs/audiovideo/list` |
| AI工具管理 | 图片工具管理 | `/tools/imagetoolslist` |
| | 音视频工具管理 | `/tools/audiovideotoolslist` |
| | SEO配置 | `/tools/seo` |
| 任务奖励管理 | 奖励数据概览 | `/reward/summary` |
| | 智点奖励数据列表 | `/reward/list` |

### 2.2 关键页面现状

**AI模型管理（/serve/aimodel）**
- 筛选区：模型名称、状态、计费方式
- 表格列：模型名称、前台分类、计费方式、状态（已上架/未上架）、最近修改时间、操作（编辑）
- 交互：点击"编辑"弹出抽屉面板，包含基础信息和前台展示
- 问题：上架/下架需进入编辑抽屉才能操作，高频操作路径过长

**模型成本管理（/serve/cost）**
- 筛选区：模型名称、渠道、是否应用独属、成本计算方式
- 表格列：模型名称、渠道、成本计算方式、是否应用独属、操作（详情）
- 交互：三栏布局，展示输入价格/补全价格/缓存价格，有"同步数据"按钮
- 问题：只有单价配置，无实际消耗汇总；同步需逐个模型操作

**模型任务日志（/logs/list）**
- KPI卡片：任务总数、成功数、进行中数、失败后退款数、消耗智点、成本总计(元)
- 筛选区：任务ID、对话名称、模型、用户、模型类型、扣费状态
- 问题：无日期范围筛选；成本只反映模型任务，不含图片/音视频工具

**图片工具任务日志（/logs/imagetool/list）**
- KPI卡片：与模型任务日志相同的6个指标
- 问题：与模型任务日志结构一致但分散在不同页面，成本需跨页核对

**奖励数据概览（/reward/summary）**
- 当前仅显示"欢迎来到系统后台"，无实质内容

### 2.3 核心痛点总结

| # | 痛点 | 影响 |
|---|------|------|
| 1 | "接入服务管理"命名不直观 | 运营不理解菜单含义，需额外解释 |
| 2 | 模型上架/下架需进入编辑抽屉操作 | 高频操作路径过长 |
| 3 | 成本同步需逐个模型点击"同步数据" | 批量操作缺失，效率低 |
| 4 | 3类任务日志分散在独立页面 | 需逐页查看才能了解全貌 |
| 5 | 成本数据分散在3个日志页面的KPI卡片中 | 无法一眼看到总成本，核对困难 |
| 6 | 日志页面无日期范围筛选 | 无法按时间段核对成本 |
| 7 | 奖励数据概览页为空 | 点击后无内容，产生困惑 |

## 三、优化方案

### 3.1 菜单命名与分组重组

目标：让运营看到菜单名就知道干什么，不需要额外解释。

#### 3.1.1 菜单重命名

| 当前名称 | 优化后名称 | 理由 |
|---------|----------|------|
| 接入服务管理 | 模型管理 | 实际操作是模型上下架+成本同步，"接入服务"是技术语言 |
| AI模型管理 | 模型上下架 | 明确操作动作，不是模糊的"管理" |
| 模型成本管理 | 模型成本 | 简化，去掉"管理"后缀 |
| 服务日志管理 | 任务日志 | 简化，去掉"服务"前缀 |
| AI工具管理 | 工具管理 | 简化，去掉AI前缀 |
| AI用户管理 | 用户管理 | 同上 |
| AI交易管理 | 交易管理 | 同上 |
| 任务奖励管理 | 奖励管理 | 同上 |

#### 3.1.2 菜单分组调整（按使用频率排序）

| 序号 | 优化后菜单名 | 子菜单 | 说明 |
|------|------------|--------|------|
| 1 | 模型管理 | 模型上下架、模型成本 | 运营最常操作 |
| 2 | 工具管理 | 图片工具管理、音视频工具管理、SEO配置 | 工具配置 |
| 3 | 任务日志 | 模型任务日志、图片工具任务日志、音视频工具任务日志 | 查看运营数据 |
| 4 | 交易管理 | 订单管理 | 订单核对 |
| 5 | 用户管理 | 用户列表 | 用户查看 |
| 6 | 奖励管理 | 奖励数据概览、智点奖励数据列表 | 奖励发放 |

排序逻辑：日常高频操作在前，低频查看在后。

验收标准：
- [ ] 所有菜单名称按上表更新
- [ ] 菜单顺序按上表排列
- [ ] 原有路由路径不变（仅改显示名称，不改path）
- [ ] 菜单级权限配置仍按原有菜单项生效

### 3.2 模型管理操作路径优化

目标：缩短高频操作路径，减少点击次数。

#### 3.2.1 模型列表增加快捷上架/下架操作

当前：表格操作列只有"编辑"，上架/下架需4步（编辑->打开抽屉->切换状态->保存）。
优化：在表格操作列增加快捷按钮，1步完成上架/下架。

实现方式：
- 表格"操作"列由 [编辑] 改为 [上架/下架] [编辑]
- 状态为"未上架"时显示"上架"按钮（绿色），点击后二次确认，确认后调用现有保存接口
- 状态为"已上架"时显示"下架"按钮（红色），同样二次确认
- 成功后刷新当前列表

注意：复用现有保存接口，不新增后端接口。

#### 3.2.2 模型成本批量同步

当前：成本详情面板中每个模型有独立的"同步数据"按钮，需逐个点击。
优化：在模型成本管理列表页顶部增加"批量同步"按钮。

实现方式：
- 筛选区右侧增加 [批量同步] 按钮
- 点击后对当前筛选结果中的所有模型执行同步
- 完成后提示"同步完成，成功X个，失败X个"

注意：循环调用现有"同步数据"接口，不新增后端接口。

验收标准：
- [ ] 模型列表操作列有上架/下架快捷按钮
- [ ] 点击上架/下架有二次确认
- [ ] 模型成本管理列表页有"批量同步"按钮
- [ ] 以上操作复用现有接口

### 3.3 任务日志整合与成本汇总

目标：让运营能一眼看到所有任务类型的关键指标和总成本。

#### 3.3.1 任务日志页面增加日期范围筛选

当前：3个日志页面都无日期范围筛选。
优化：在3个日志页面筛选区左侧增加日期范围选择器。

实现方式：
- 增加日期范围选择器，默认近7天
- 选择后按执行时间过滤，KPI卡片同步更新

注意：如后端不支持时间参数，需扩展接口参数（非新增接口）。

#### 3.3.2 任务日志总览入口

当前：进入"任务日志"菜单后直接显示子菜单，需逐个点击查看。
优化：点击"任务日志"一级菜单时展示跨类型汇总概览。

推荐方案A：概览面板
- 3行KPI卡片，分别对应模型任务、图片工具任务、音视频工具任务
- 顶部合计行：三类任务的总数、总消耗智点、总成本
- 支持按日期范围筛选
- 下方为3个子菜单入口卡片

验收标准：
- [ ] 3个日志页面都有日期范围筛选器，默认近7天
- [ ] 点击"任务日志"一级菜单展示跨类型汇总面板
- [ ] 合计行正确显示三类任务的总成本求和
- [ ] 点击入口卡片可跳转到对应日志详情页

#### 3.3.3 KPI卡片增加环比提示（P2）

在每张KPI卡片下方增加环比变化小字，如"环比上升X%"。

### 3.4 奖励数据概览页补充

当前：仅显示"欢迎来到系统后台"。
优化：补充实际内容或改为合理占位说明。

建议内容：KPI卡片（累计发放智点、今日发放量、本周发放量、累计奖励人数）+ 近期奖励发放记录表格。

注意：如涉及后端新增聚合接口属于范围外，与开发确认是否可前端聚合。无法实现则至少改为"暂无奖励数据"。

验收标准：
- [ ] 页面不再显示"欢迎来到系统后台"
- [ ] 如能实现，展示奖励汇总KPI和近期记录表格
- [ ] 如短期无法实现，改为合理占位说明

### 3.5 列表页表格列头优化

当前：部分列头被截断显示为"模..."、"关..."。
优化：调整列宽确保完整显示，长内容列增加hover提示。

- "模型类型"列改为"类型"
- "关联状态"列改为"状态"
- 长内容列（任务ID、对话名称）增加el-tooltip

验收标准：
- [ ] 所有表格列头完整显示
- [ ] 长内容列hover显示完整内容
- [ ] 列宽调整后不影响筛选和分页

## 四、优先级排序

| 优先级 | 优化项 | 理由 |
|--------|--------|------|
| P0 | 3.1 菜单命名与分组重组 | 成本最低、见效最快 |
| P0 | 3.2.1 模型快捷上架/下架 | 运营最高频操作 |
| P0 | 3.2.2 成本批量同步 | 运营高频操作 |
| P1 | 3.3.1 日志日期范围筛选 | 成本核对的基础能力 |
| P1 | 3.3.2 任务日志总览入口 | 解决成本分散的核心痛点 |
| P1 | 3.5 表格列头优化 | 基础体验问题，改动小 |
| P2 | 3.3.3 KPI环比趋势 | 锦上添花 |
| P2 | 3.4 奖励概览页补充 | 使用频率低 |

## 五、不在本次范围内

- 新增功能模块
- 后端接口/数据结构改动（最多扩展时间筛选参数）
- 权限体系重构
- 移动端适配
