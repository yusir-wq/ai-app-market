## 1. 功能范围

本次版本包含以下功能：

1. 从站长素材相关页面向 AI 应用广场引流。
2. 用户完成系统规定的任务后获得智点奖励，并可查看奖励明细。
3. 后台新增引流数据统计、智点奖励数据列表和基础数据分析。
4. 后台新增用户端各 AI 工具的 SEO 配置。
5. 后台在图片工具场景配置中新增 SEO 配置，并由后端为每个场景提供简短、唯一且稳定的访问路径。
6. 完成1.3遗留的免扣费记录、模型成本汇总及音视频工具前后台优化。

### 2.4 动画详情页

- 动画详情页在“一键生成同款视频”按钮左侧展示视频生成引流入口。
- 用户点击后进入 AI图片生成视频工具页面。
- 系统将当前动画详情页的预览图自动带入图片上传区域并展示预览。
- 系统从“动画简介”中提取核心描述，自动带入视频文案输入区域。
- 提取时不带入“动画简介”标签；删除文案开头至“是一款”的素材名称及固定表述，并删除结尾“的动画素材下载。”，去除结果首尾空格后带入。
- 示例：“蝶舞翩翩蓝色蝴蝶展翅flash动画是一款通过生动的视觉效果和细腻的动态表现，展现蓝色蝴蝶优雅飞舞、自由自在的美丽画面的动画素材下载。”提取为“通过生动的视觉效果和细腻的动态表现，展现蓝色蝴蝶优雅飞舞、自由自在的美丽画面”。
- 只有在“是一款”和结尾固定表述均可识别、且提取结果不为空时带入文案。提取失败时不带入原始整段简介，文案输入区域保持为空，预览图仍正常带入。
- 需要记录动画详情页引流入口的曝光、点击及后续转化数据。

### 2.5 素材会员汇总页

- 素材会员汇总页展示开通素材会员获得智点的引流入口。
- 用户点击后进入 AI 应用广场。
- 需要记录素材会员汇总页引流入口的曝光、点击及后续转化数据。

### 2.6 跨站用户身份与登录

素材站游客：

- 游客可以查看素材页面并点击引流入口。
- 游客到达 AI 应用广场后，不强制登录。
- 游客点击“生成”时进行登录校验，并通过手机号注册或登录。
- 注册或登录成功后继续用户本次生成流程，保留已自动带入的素材图片和页面选择状态。
- 注册或登录后，将本次匿名引流来源与 AI 应用广场账号关联。

素材站登录用户：

- 已在素材站登录的用户点击引流入口后，到达 AI 应用广场时自动登录。
- 用户首次进入 AI 应用广场且系统新建 AI 应用广场账号时，计为新增注册。
- 用户已有 AI 应用广场账号时，只计为自动登录或回访，不重复计为新增注册。

用户注册时，以注册发生前最后一次有效引流点击作为注册来源。注册成功后锁定该来源，后续点击其他引流入口不得修改。

任务交互规则：

使用类与会员任务：

- 会员任务点击“去完成”后进入站长素材会员集合页。

### 3.2 任务状态

任务至少包含以下状态：

- 去邀请：特殊按钮，仅用于“邀请好友一起用”任务；存在可用邀请名额时显示，点击后打开 1.3 已有邀请窗口。
- 去完成：当前任务仍可继续获得奖励；点击后执行该任务对应的操作或进入目标页面。
- 已赚到：当前任务已不能继续获得奖励。适用于一次性任务已完成、邀请名额全部使用，或“天天赚智点”累计奖励达到 50000 智点。

可重复奖励且尚未达到上限的任务，每次奖励到账后仍显示“去完成”。会员任务不设置奖励上限，始终显示“去完成”。

“已赚到”为不可点击状态，不再执行跳转、复制或邀请操作。

任务是否完成由系统根据真实业务结果判断，只进入任务页面或点击操作按钮不算完成任务。

### 3.3 奖励发放

公共发放规则：

- 用户满足任务完成条件后，系统向用户发放对应智点。
- 除明确设置为可重复奖励的任务外，同一任务仅发放一次奖励。
- 同一任务达到规定完成次数后，不再重复发放奖励。
- 奖励发放后更新用户智点余额、任务状态和奖励明细。
- 奖励发放失败或延迟时保留处理状态，不能重复发放同一笔奖励。

邀请与好友消费奖励：

- 邀请任务沿用 1.3 的邀请关系、邀请名额和奖励结果；1.4 只展示进度与状态，不重复发放同一笔邀请奖励。
- 好友消费奖励只统计通过当前用户邀请关系注册的好友，同一好友仅以首次满足条件的订单触发一次。
- “注册当天”按中国标准时间（UTC+8）计算，范围为注册日期当日 00:00（含）至次日 00:00（不含）。

新手体验与日常奖励：

- 新手体验任务从本版本生效时间开始计算，生效前的使用记录不补发奖励，也不自动完成任务。
- 本版本生效后首次成功使用对应工具时，只发放新手体验奖励；从下一次成功使用开始发放日常奖励。
- 6 项日常任务共享 50000 智点累计上限。达到上限后全部显示“已赚到”，不再发放奖励。
- 同一用户同时完成多个日常任务时统一校验共享上限，累计发放不得超过 50000 智点。

会员与退款：

- 素材站与 AI应用广场共享账号，但共享账号本身不代表用户已注册 AI应用广场；用户实际首次进入并在 AI应用广场形成注册时间后，才可收到会员任务奖励。
- 只处理支付成功时间达到本版本生效时间的素材会员订单；本版本生效前的订单不追溯、不发放奖励。
- 用户支付会员订单时若尚无 AI应用广场注册时间，系统保留该订单的奖励资格，暂不发放智点。
- 用户后续首次进入并形成 AI应用广场注册时间后，系统自动发放此前所有符合条件的会员订单奖励，不设置补发期限；多笔订单分别发放。
- 每笔会员订单只能发放一次奖励，注册或其他事件重复通知时不得重复发放。
- 会员奖励按实际发放时该任务最新生效的奖励智点发放，不采用订单支付时的历史奖励金额。
- 好友套餐订单或素材会员订单退款后不自动扣回已发智点；需要时通过现有人工智点调整流程处理。

### 3.4 我的奖励

“我的奖励”展示用户通过任务获得的智点明细。

每条明细展示：

- 奖励来源。
- 获得智点。
- 到账时间。

页面同时展示累计获得的智点。无奖励记录时展示空状态，并引导用户前往任务中心完成任务。

### 3.5 奖励到账提示

- 用户位于 AI应用广场任意页面时，奖励成功到账后立即展示全局到账提示，不要求用户停留在任务中心或对应工具页。
- 用户不在 AI应用广场、页面已关闭或处于离线状态时，系统保存尚未展示的到账通知；用户下一次进入 AI应用广场时展示一次。
- 用户离开期间存在多笔尚未展示的奖励时，合并为一条提示，展示奖励笔数和获得智点合计，例如：“3笔任务奖励已到账，共获得2300智点”。
- 提示内容包含到账智点、完成的任务名称和奖励已发放说明。
- 单笔奖励展示对应任务名称和到账智点；多笔合并提示不逐项展示任务名称，用户可进入“我的奖励”查看明细。
- 提示窗口显示 5 秒后自动关闭，同时提供手动关闭入口和“更多奖励”入口。
- 点击“更多奖励”后进入任务中心。
- 到账提示是否成功展示、自动关闭或被用户手动关闭，均不影响奖励到账；奖励记录始终保留在“我的奖励”中。

### 3.6 赚点王者榜

- 榜单积分统计任务中心全部四类任务已经到账的智点，包括邀请好友赚智点、新手体验赚智点、天天赚智点和站长之家指定会员专属福利；会员任务奖励计入榜单积分。
- 非任务奖励、人工智点调整及尚未到账的任务奖励不计入榜单积分。
- 冷启动使用内部用户的真实任务数据，不使用虚构账号、虚构任务或后台注入的榜单数据。
- 内部用户使用正常账号，按与普通用户相同的任务规则获得智点并进入榜单。
- 榜单用户ID按7位数字脱敏展示，格式为“前2位＋***＋后2位”，例如“12***67”。
- 内部账号在后台标记，其数据不计入正式的注册、活跃和转化统计。
- 内部用户不刻意刷高榜单分数；外部用户参与后，通过真实任务积分自然进入并超过内部用户。

### 4.1 引流数据分析

#### 4.1.1 引流漏斗

引流转化漏斗按以下链路统计：

引流页访问 → 引流位置点击 → 到达 AI 应用广场 → 注册 → 首次成功使用 → 首次支付。

注册包含两种方式：素材站游客在 AI应用广场完成手机号注册；素材站登录用户首次进入 AI应用广场并自动创建本项目账号。两种方式统一计入注册人数并按用户去重。已有 AI应用广场账号的用户再次自动登录只属于登录或回访，不计入注册人数和新增用户漏斗。

“首次成功使用”是指用户首次成功完成任意一个 AI 工具的核心操作，举几个例子：

- AI聊天：成功收到一次完整回复。
- AI图像工具：成功生成一张图片。
- AI文字转语音：成功生成一条语音。
- AI语音转文字：成功获得一次转写结果。

#### 4.1.2 引流数据概览

页面展示数据更新时间和刷新按钮。点击刷新后按当前筛选条件重新查询，刷新期间展示加载状态。

概览展示全部引流页面汇总后的数据：

- 引流页总 PV。
- 引流页总 UV。
- 引流点击总量。
- 引流点击用户数。
- 到达 AI 应用广场用户数。
- 引流注册人数。
- 首次成功使用人数。
- 首次支付人数。
- 首次支付金额。
- 引流用户累计支付金额。

概览展示以下转化率：

- 引流点击率＝引流点击用户数÷引流页总 UV。
- 点击次数转化率＝引流点击总量÷引流页总 PV。
- 到达率＝到达 AI 应用广场用户数÷引流点击用户数。
- 注册转化率＝引流注册人数÷到达 AI 应用广场用户数。
- 首次成功使用转化率＝首次成功使用人数÷引流注册人数。
- 首次支付转化率＝首次支付人数÷引流注册人数。
- 全链路支付转化率＝首次支付人数÷引流页总 UV。
- 首次支付客单价＝首次支付金额÷首次支付人数。

分母为 0 时，转化率展示为“—”。

较上期数据：

- 概览指标展示较上期变化时，使用相邻的上一段同类时间范围比较。
- 按日查看时与前一个自然日比较；按月查看时与前一个自然月比较；近7日与此前7个自然日比较；自定义时间段与此前相同自然日数量的时间段比较。
- 当前自然日或自然月尚未结束时，上期只取相同进度的数据，避免完整周期与未完整周期直接比较。
- 人数、次数、金额等绝对值指标：上期大于0时，按“（本期值－上期值）÷上期值”展示增长或下降百分比；上期为0且本期大于0时显示“新增”；上期与本期均为0时显示“持平”。
- 转化率类指标使用百分点比较，例如上期为0%、本期为10%时显示“较上期提升10个百分点”。
- “新增”和“持平”支持查看本期值与上期值；不得将上期为0、本期大于0的情况展示为“—”“∞%”或固定“+100%”。

趋势分析：

- 支持查看访问 UV、引流点击用户数和首次支付人数的变化趋势。
- 按日查看时展示小时趋势；按月或自定义时间段查看时展示每日趋势。

指标说明：

- 页面提供“指标口径”入口，集中展示核心公式、去重规则、时间口径、支付口径及内部用户隔离规则。
- 概览指标和转化率名称提供简短释义，用户无需离开页面即可查看。
- 页面提供加载、空数据和加载失败状态；空数据支持重置筛选，加载失败支持重新加载。

#### 4.1.5 指标说明与统计规则

| 指标名称 | 指标定义 | 统计口径 | 边界说明 |
| --- | --- | --- | --- |
| 引流页 PV | 引流页面被有效访问的次数 | 页面成功加载一次计 1 次，同一用户重复访问重复累计 | 只统计设置了引流位置的页面；刷新或再次进入均产生新的 PV |
| 引流页 UV | 访问过引流页面的去重用户数 | 在所选时间范围内按用户去重 | 游客按匿名ID识别，注册或登录后与账号关联；概览总 UV 跨全部引流页去重，不能累加各页面 UV |
| 引流位置展示次数 | 引流位置实际展示给用户的次数 | 引流位置进入可见区域一次计 1 次，同一页面内反复滚动不重复计数 | 折叠区域内尚未展开的工具不计展示；展开后实际显示时再计数 |
| 引流点击量 | 用户点击引流入口的总次数 | 每次有效点击计 1 次，同一用户重复点击重复累计 | 分页面、位置、素材分类和推荐工具分别记录；点击后未成功到达 AI应用广场仍计点击 |
| 引流点击用户数 | 点击过引流入口的去重用户数 | 在所选时间范围及当前查看维度内按用户去重 | 同一用户重复点击只计 1 人；游客注册或登录后合并为同一用户 |
| 到达 AI应用广场用户数 | 点击引流入口后成功打开目标页面的去重用户数 | 目标页面成功加载且保留对应引流来源时计入，在所选时间范围内按用户去重 | 点击后关闭页面、加载失败或来源无法识别时不计到达 |
| 引流注册人数 | 由引流用户首次创建 AI应用广场账号的人数 | 手机号注册与素材站登录用户首次进入后自动创建项目账号合并统计，按用户去重 | 已有 AI应用广场账号再次自动登录只属于登录或回访，不计入注册人数 |
| 首次成功使用人数 | 引流注册用户中首次成功完成任意 AI 工具核心操作的人数 | 产生符合第4.1.1节定义的首次成功结果时计入，按用户去重并固定归属于注册来源 | 只进入工具页、提交后失败或未获得成功结果均不计入；已有项目账号不计入 |
| 首次支付人数 | 引流注册用户中完成第一笔成功支付的人数 | 第一笔支付成功时计入，按用户去重并固定归属于注册来源 | 支付失败、取消或非第一笔成功订单不计入；已有项目账号不计入 |
| 首次支付金额 | 首次支付用户第一笔成功支付订单的实付金额合计 | 汇总首次支付人数对应第一笔成功订单的实付金额，并固定归属于注册来源 | 不含支付失败、取消订单和后续订单金额 |
| 累计支付金额 | 引流注册用户全部成功支付订单的实付金额合计 | 汇总引流注册用户在所选时间内产生的成功支付订单实付金额，并固定归属于注册来源 | 支付失败或取消订单不计入；已有项目账号后续通过引流入口进入产生的支付不计入；与首次支付金额分开统计 |
| 引流点击率 | 访问引流页的用户中发生点击的比例 | 引流点击用户数 ÷ 引流页 UV | 分母为 0 时展示“—”；用于概览和引流页面维度 |
| 点击次数转化率 | 每次引流页访问产生点击的次数水平 | 引流点击量 ÷ 引流页 PV | 允许同一用户多次点击；结果可能超过 100%；分母为 0 时展示“—” |
| 引流位置点击率 | 引流位置展示后产生点击的比例 | 引流位置点击次数 ÷ 引流位置展示次数 | 按页面、位置、素材分类和推荐工具分别计算；分母为 0 时展示“—” |
| 到达率 | 点击用户成功到达 AI应用广场的比例 | 到达 AI应用广场用户数 ÷ 引流点击用户数 | 分母为 0 时展示“—” |
| 注册转化率 | 到达用户中首次注册 AI应用广场的比例 | 引流注册人数 ÷ 到达 AI应用广场用户数 | 两种注册方式合并去重；已有账号再次自动登录不计入；分母为 0 时展示“—” |
| 首次成功使用转化率 | 引流注册用户中完成首次成功使用的比例 | 首次成功使用人数 ÷ 引流注册人数 | 分母为 0 时展示“—” |
| 首次支付转化率 | 引流注册用户中完成首次支付的比例 | 首次支付人数 ÷ 引流注册人数 | 分母为 0 时展示“—” |
| 全链路支付转化率 | 引流页访问用户最终完成首次支付的比例 | 首次支付人数 ÷ 引流页 UV | 概览使用跨全部引流页去重后的 UV；分母为 0 时展示“—” |
| 首次支付客单价 | 首次付费用户的平均首次实付金额 | 首次支付金额 ÷ 首次支付人数 | 分母为 0 时展示“—” |

| 行为时间 | 访问、点击、注册、成功使用和支付分别按各自发生时间筛选 |

## 6. 1.3遗留优化

### 6.1 工具免扣费记录

- 后台开启某个工具不扣费后，用户成功或失败使用该工具时，仍按正常流程生成后台任务日志。
- 后台任务日志继续展示本次任务的工具、模型、执行状态、发生时间及相关任务数据，用户扣费显示为 0 智点。
- 前台用户消费明细仍生成对应记录，展示工具名称、使用时间、任务结果及消费 0 智点，不能因未扣费而隐藏本次使用。
- 工具免扣费只影响向用户扣除的智点，不影响任务记录和模型真实成本统计。

### 6.2 模型成本管理

- 优化后台工具、模型、用户计费和平台成本之间的管理关系，解决不同负责人分别维护时配置分散、口径不一致和数据难以核对的问题。
- 明确区分用户计费与模型成本，确保工具使用模型、用户实际扣费和模型实际成本能够正确关联并追溯。
- 配置调整不能影响历史任务已经产生的计费与成本数据。
- 模型成本管理需按模型展示汇总成本总金额；工具免扣费期间产生的实际模型成本仍需计入。
- 具体模块结构、字段和操作方式由研发结合现有后台统一优化。
