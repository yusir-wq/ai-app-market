### 使用说明

1. 所有 Prompt 已统一前缀，差异仅集中在 **发色 / 肤色 / 背景色 / 表情线** 四个维度，保证同一系列感。
2. 同类型音色（如多位「美式英文女」）通过红/蓝 pastel 的细微变化 + 背景补色来区分。
3. 如需批量出图，建议按顺序固定 `seed` 或同一次模型会话运行，以进一步锁死风格一致性。
4. 由于 48×48 极小尺寸，建议对生成结果做批量 48×48 中心裁剪并合并为 Sprite Sheet。
