## 一、运营后台优化

### 1.1 目标与原则

让运营在**一个页面回答一个完整的业务问题**,不靠口头带教就能上手:

| 运营的问题 | 优化后去哪找 |
|-----------|-------------|
| 平台上有什么内容?怎么上下架? | 工具 |
| 平台收了多少钱?要给上游付多少? | 交易 |
| 花了多少钱?谁在调?有没有异常?奖励发了多少? | 运营数据 |
| 谁在用?智点情况怎么样? | 用户 |

### 1.3 命名规范

#### 1.3.1 计费与状态命名(✅已定,以最新画板为准)

| 旧命名 | 新命名 | 说明 |
|--------|--------|------|
| 灵活计费 | **倍率扣费** | 扣费 = 上游成本 × 倍率,倍率即利润空间;编辑时输入售价倍率 |
| 固定计费 | **固定扣费** | 每次扣固定智点,与上游成本无关;编辑时输入售价智点 |
| 固定计费智点 | **智点售价**(必填) | 仅固定扣费时显示,如"490智点/次" |
| 预扣智点数 | **预扣智点** | 仅倍率扣费:先冻结该额度,实际成本结算后多退少补 |
| 未开启 | **未开启计费** | 计费方式下拉选项(倍率扣费/固定扣费/未开启计费) |
| 已上架/未上架 | **上架/下架** | 状态下拉选项(全部/上架/下架) |

> 注1:早期方案中的"按量计费/按次计费"命名已被上表取代,不再采用。
> 注2:⚠️"预扣"命名不一致——8/20讨论记录为"预扣额度(智点)",最新画板为"预扣智点"。本稿以画板为准,评审时确认。
