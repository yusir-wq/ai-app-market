## 统计汇总

| 违规类型 | 涉及文件数 | 模式 |
|---------|-----------|------|
| **D - 下载按钮** | 10（全部） | ghost 样式 → 下载按钮规范 |
| **G - Select 组件** | 8 | 缺 `shadow-none` 或用错圆角 |
| **C - 参数设置阴影** | 8 | 不应有 `CARD_SHADOW` |
| **A - 标题颜色** | 4 | `text-foreground` → `text-[#3f4558]` |
| **B - 卡片圆角** | 3 | `rounded-[16px]` → `rounded-[12px]` |
| **H - 图标混用** | 2 | 残留 `lucide-react` 导入 |

**合计**：共约 48 处违规，其中 D 类（下载按钮）14 处、G 类（Select）13 处、C 类（阴影）8 处为最普遍的问题。
