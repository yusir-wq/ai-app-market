# AI应用广场 V1.3 页面重构 - 完整设计规范汇总

> 本文档综合了 `inner-tool-prototype-pm-guide.md` 产品规范、Background 页面 UI 实测规范、quick-start 页面 UI 规范。
> 用于指导后续 V1.3 版本的页面重构实施。

---

## 一、项目定位与第一性原则

### 1.1 产品定位
- **目标用户**：AI 小白用户
- **核心价值**：多模型、多工具、便宜好用
- **当前模板工具**：AI 换背景（`#/image-tools/ai-background`）
- **复用工具列表**：AI 扩图、AI 写真、AI 商品海报、AI 风格转换、AI 配色重绘

### 1.2 四个设计原则
1. **信息少而准**：每个区块只承担一个任务，不堆参数、不堆说明、不用专业术语。
2. **操作顺而稳**：上传、选择、生成、查看结果、下载必须形成闭环。
3. **视觉一致**：框架、字体、颜色、圆角、阴影、图标、按钮和 hover 状态沿用已确认规范。
4. **迭代可复用**：AI 换背景作为通用模板，其他图像工具按同一结构复用和变体化。

## 二、页面框架规范（不可动）

### 2.1 必须保留的框架元素
1. 左侧品牌区、透明 logo、平台名称和 slogan
2. 左侧折叠/展开按钮及自动折叠规则
3. 左侧底部剩余智点、智点充值、邀请好友、账号入口
4. 右侧白色画布和统一内容限宽
5. 右下角悬浮功能入口
6. 底部备案和版权信息

### 2.2 框架尺寸约束

| 项目 | 数值 | 说明 |
|------|------|------|
| Sidebar 展开宽度 | `252px` | 快速开始页/首页展开态 |
| Sidebar 折叠宽度 | `76px` | 工具内页默认折叠态，与之前分析一致 |
| 右侧内容最大宽度 | `1440px` | `--content-max` |
| 右侧内容最小宽度 | `1080px` | `--content-min` |
| 右侧内容安全间距 | `34px` | `--content-gutter` |
| 页面最小验收宽度 | `1400px` | 不得低于此宽度 |
| 主内容区内边距 | `18px 12px 0 0` | 上18px，右12px |
| 首页和内页菜单列表间距 | `4px` | 左侧菜单项之间 |

### 2.3 左侧菜单规范

#### 首页菜单
- 普通菜单字号：`14px`，字重 `400`
- 内页返回入口字号：`12px`，视觉弱化
- 菜单项间距：`4px`
- hover：淡白背景
- active：纯白背景

#### 内页工具菜单
- 第一项为返回入口：
  - 展开态文案：`AI图像工具`
  - hover 提示：`返回主页，发现更多AI工具`
  - 图标和文字弱化，不要做得像当前工具标题
- 当前工具选中态必须持续可见
- 选中态：纯白背景，文字和图标为主色
- hover 态：淡白背景，不改变文字和图标颜色
- 折叠态必须有白底 tooltip，不能黑底

#### 左侧底部区域
- 剩余智点文案和数值：`14px`
- 智点充值、邀请好友、账号 ID：`14px`
- 邀请好友辅助文案：`10px`

## 九、图标规范

1. **UI 图标**：使用 Phosphor Icons（`@phosphor-icons/web` regular + duotone）
2. 不临时手绘 SVG，不自创抽象图标，不混用风格差异明显的图标库
3. 工具图标、按钮图标、提示图标保持同一套 Phosphor 线性风格
4. **品牌 logo**：透明 PNG `assets/ai-logo-transparent-cropped.png`
5. **厂商/品牌/模型图标**：必须使用真实品牌图标或已确认本地资源
   - 不允许用首字母、渐变块、随机图标替代
   - 同一厂商在所有页面使用同一套 logo 资源和裁切比例
6. **工具类图标 vs 模型/厂商图标**：
   - 工具功能图标 → Phosphor
   - 模型/厂商识别图标 → 真实品牌资源

## 十、工具内页信息架构（AI换背景模板）

### 10.1 页面结构顺序
1. 顶部工具条
2. 使用指南区
3. 操作区与风格/场景选择区
4. 生成结果
5. 生成历史

### 10.2 顶部工具条
- 左侧：工具图标 + 工具名称
- 右侧：`收藏`、`分享`（描边按钮）
- 工具条是页面背景上的固定横条，不是突出的卡片
- 底部分割线从左到右连贯
- 收藏提示文案：`按 ⌘D / Ctrl+D 将当前工具收藏到浏览器，后续使用更便捷`

### 10.3 使用指南区
- 标题：`使用指南`
- 标题不用蓝色，不加粗过度
- 正文说明工具能做什么
- 费用展示：`使用费用：490 智点/次（约 0.49 元）`
- 文案让小白秒懂，不堆技术词
- 费用透明可见但不刺眼

### 10.4 上传区

#### 上传前
- 整个上传区域可点击，支持拖拽上传
- 主文案：`点击或拖拽上传图片`
- 格式限制两行展示：
  - `支持 PNG、JPG、JPEG、WebP`
  - `单张不超过 10MB`
- 采用加号类图片图标

#### 上传后
- 上传框尺寸不变
- 只展示图片预览
- 图片必须保持真实比例，不拉伸、不强行填满
- 不展示文件名、大小、删除按钮
- hover 时图片中间出现 `重新上传` 按钮

#### 上传提示
- 文案：`上传即表示您确认拥有图片及其中人物、商品、素材的合法授权，并承诺不用于违法违规用途。`
- 提示前需要有轻量提示图标

### 10.5 生成设置
- 模块标题：`生成设置`
- 每个参数是一整行高一点的下拉框样式
- 左侧为参数名，右侧为当前值
- 不使用浏览器默认 select

#### 图片比例
- 当前默认：`接近原图`
- 下拉用比例图形 + 数字展示
- 比例图形固定宽度占位，保证数字垂直左对齐
- 不要把 `接近原图` 改成 `原图`

#### 背景色
- 支持自动推荐和颜色选择
- 自动推荐只保留一个选项，文案为 `自动推荐`
- 自动推荐使用描边按钮样式，不使用背景色
- hover 使用通用浅紫背景 `#f0f3ff`
- 颜色按一级分组 + 二级色块展示
- 色块 hover 展示颜色名称
- 选中后展示颜色名称 + 色块

#### 风格
- 风格不在下拉内选择，只从右侧风格区选择
- 左侧参数自动同步选中的风格
- 展示格式：`分类/风格名称`，例如 `分类一/摄影棚`
- 下拉时只提示：`请在右侧选择风格`

#### 生成按钮
- 文案：`立即生成`
- 主按钮样式
- hover 不透明度为 `80%`
- 阴影克制
- 按钮下居中弱化费用文案：`490 智点/次（约 0.49 元）`
- 不要写成 `使用费用：490 智点/次...`

### 10.6 选择风格区
- 标题：`选择风格`
- 标题字号：`18px`
- 分类 tab：分类一、分类二、分类三、分类四、分类五、分类六（当前占位）
- tab 样式沿用 AI换背景页，不新增色系
- 风格卡片只展示图片/色块和场景名称
- 不展示描述、标签、按钮、图标等额外信息
- 选中后同步左侧风格参数

### 10.7 生成结果
- 未生成前不展示整块区域
- 点击 `立即生成` 后页面自动滚动到生成结果位置
- 标题：`生成结果`，字号 `18px`
- 成功文案：
  - 主文案：`生成成功！`
  - 提示：`AI生成内容，仅供参考，请勿用于违法违规用途。`
- 结果参数：风格、比例、尺寸、大小、格式
- 预览图：
  - 使用固定背景容器
  - 保持真实比例，不变形
  - 可用棋盘格表达透明/预览环境
  - 两类水印：右下角 `AI生成` + 全局较弱斜向网格/线条水印
- 预览提示：`当前为带水印预览图，下载后可获取原图。右下角"AI生成"为合规标识，将随原图保留。`
- 下载按钮：`下载图片`，主按钮样式，点击前必须弹确认窗口

### 10.8 下载确认弹窗
- 所有下载入口统一确认窗口
- 文案：`下载即表示您确认对上传素材拥有合法使用权，知悉该图片为AI生成/编辑内容，并自行承担使用责任。`
- 操作：`取消`、`确认并下载`
- 两个按钮同行展示，`确认并下载` 在右侧
- 属于强调确认弹窗：确认按钮宽度大于取消按钮，高度一致，按钮不加阴影
- 取消 hover 只改变背景，不改变文字颜色

### 10.9 生成历史
- 标题：`生成历史`，字号 `18px`
- 标题右侧单行提示：`历史记录将为您保留 3 天。为避免过期丢失，请及时下载到本地设备。`
- 历史项展示：图片、风格、尺寸、大小、时间、下载、删除
- 时间规则：
  - 今天：`今天 HH:mm`
  - 非今天：`YYYY-MM-DD HH:mm`
- 下载在左，删除在右
- 下载按钮样式与收藏/分享一致，同样弹下载确认
- 删除按钮视觉比下载弱化，使用更淡文字色和弱化描边/背景
- 删除必须先弹出确认窗口，确认后才删除
- 删除确认属于普通确认弹窗：确认与取消按钮宽度一致、高度一致，不加阴影

## 十二、交互规范

1. 所有可点击区域 hover 必须是鼠标手
2. hover 默认不改变文字色和图标色，只改变轻背景、透明度、辅助动作显隐
3. 左侧菜单规范独立：hover 淡白，active 纯白
4. 弹窗、下拉、tooltip 需要有轻微延迟，避免误触
5. 从触发区移动到浮层时不能立刻消失
6. 本期只做视觉预留的点击事件，需要记录到待补任务
7. 用户点击生成后，必须能看到反馈；结果在页面下方时要自动滚动
8. 错误提示要放在用户看得到的位置，不要藏在按钮下面或页面底部

---

## 十三、不要做清单

1. 不要改左侧框架
2. 不要把工具内页做成独立 landing page
3. 不要把普通 hover 做成文字变蓝、图标变蓝
4. 不要滥用加粗
5. 不要用大阴影和大渐变制造"高级感"
6. 不要让上传图、结果图变形
7. 不要把合规提示藏起来
8. 不要删除已确认的下载确认
9. 不要让其他工具页展示旧占位大标题和多余说明
10. 不要把前端实现文档当产品原型规范直接照搬

## 十四、V1.3 重构实施建议

### 14.1 第一阶段：框架统一
1. 确保所有页面使用统一 Sidebar（76px 折叠 / 252px 展开）
2. 统一内容区最大宽度 1440px、最小宽度 1080px
3. 统一页面底色 `#f8faff`、卡片底色 `#ffffff`
